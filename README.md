# WINE-QUALITY-WITH-DEEP-LEARNING

# 🍷 Wine Quality Prediction using Deep Learning (ANN)

This project focuses on predicting **wine quality** using **Exploratory Data Analysis (EDA)** and an **Artificial Neural Network (ANN)** regression model.

---

## 📌 Project Highlights

* ✅ Complete **EDA with visualizations**
* ✅ **Outlier handling using IQR capping**
* ✅ **Feature importance using ExtraTrees**
* ✅ **ANN model built with Keras**
* ✅ Model evaluation using **MAE, MSE, RMSE**
* ✅ Cleaned & preprocessed real-world dataset

---

## 🧰 Technologies Used

* Python
* Pandas, NumPy
* Matplotlib, Seaborn
* Scikit-learn
* TensorFlow / Keras

---

## 📊 Dataset

Wine Quality Dataset with **1143 records & 13 features** including:

* Acidity, Sugar, Alcohol, pH, Sulphates, etc.

---

## 🧠 Model Used

* **Artificial Neural Network (ANN)**
* Hidden Layers: 128, 64
* Activation: ReLU
* Optimizer: Adam
* Loss: Mean Absolute Error

---

## 📈 Model Performance

* **MAE:** 0.49
* **MSE:** 0.41
* **RMSE:** 0.64

✅ Shows **good prediction accuracy** with low error.

---

## ✅ Final Conclusion

* ANN successfully predicts wine quality.
* Model shows strong generalization.
* Predictions closely match actual values.
